# Курсовая работа по предмету "Численные методы"

**Тема**: "Применение кокригинга для выявления проблемных участков улично-дорожной сети"

**Задание**: Получить данные о структуре улично-дорожной сети и об интенсивности движения в выбранном населенном пункте из открытых источников. Применить алгоритм кокригинга для выявления самого загруженного участка улично-дорожной сети с учетом сведений о поворотах. Оценить точность полученного результата

Файлы:
- Coursework_math.pdf - файл с математическими выкладками
- Coursework_realization.ipynb - файл с реализацией на языке Python

В папке sources/ использованная литература, в папке data/ - данные по УДС и результаты программы
